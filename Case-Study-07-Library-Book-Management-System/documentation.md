# Case Study 07: Library Book Management System

## Objective
To develop a Python program that manages a simple collection of library books by adding, viewing, and searching for books.

## Problem Description
A library needs a simple system to organize its book collection. This program allows users to add books, view all available books, and search for a particular book.

## Concepts Used
- Variables
- User Input
- Lists
- List Methods (append)
- Conditional Statements (if, elif, else)
- While Loop
- For Loop
- Break Statement

## Program Description
The program maintains a list of books.

Users can select from a menu of options:
1. Add Book
2. View Books
3. Search Book
4. Exit

Books entered by the user are stored in a list. The program displays the books and allows users to search for a book by its name.

## Features
- Add books to the collection
- View all stored books
- Search for a book
- Menu repetition using a while loop

## Conclusion
This case study demonstrates how Python lists, loops, and conditional statements can be used to create a simple library book management system.
