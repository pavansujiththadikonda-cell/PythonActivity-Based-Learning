# Case Study 06: ATM Transaction Simulator

## Objective
To develop a Python program that simulates basic ATM operations such as checking balance, depositing money, and withdrawing money.

## Problem Description
An ATM provides users with basic banking operations. This program simulates a simple ATM system where users can check their balance, deposit money, withdraw money, and exit the system.

## Concepts Used
- Variables
- User Input
- Data Types
- Arithmetic Operators
- Conditional Statements (if, elif, else)
- While Loop
- Break Statement

## Program Description
The program starts with an initial balance of Rs. 10,000.

Users can select from a menu of options:
1. Check Balance
2. Deposit Money
3. Withdraw Money
4. Exit

The program validates deposit and withdrawal amounts and prevents withdrawals that exceed the available balance.

## Features
- Balance checking
- Money deposit
- Money withdrawal
- Balance validation
- Menu repetition using a while loop

## Conclusion
This case study demonstrates how Python can be used to simulate basic ATM operations using loops, conditional statements, and arithmetic operations.
