# Case Study 05: Electricity Bill Calculator

## Objective
To develop a Python program that calculates electricity charges based on the number of units consumed.

## Problem Description
Electricity charges are calculated based on the number of units consumed by a customer. Different unit ranges may have different rates.

This program accepts the customer name and electricity units consumed, then calculates the bill using predefined electricity rate slabs.

## Concepts Used
- Variables
- User Input
- Data Types
- Arithmetic Operators
- Conditional Statements (if, elif, else)

## Program Description
The program accepts the customer's name and electricity consumption in units.

It calculates the electricity bill based on the following slab rates.

## Electricity Rate Criteria
- Up to 100 units – Rs. 2 per unit
- 101 to 200 units – Rs. 3 per additional unit
- 201 to 300 units – Rs. 5 per additional unit
- Above 300 units – Rs. 7 per additional unit

## Conclusion
This case study demonstrates how Python can be used to calculate electricity charges using conditional statements and arithmetic operations.
