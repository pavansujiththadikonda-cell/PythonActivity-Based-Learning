# Case Study 03: Student Grade Analyzer

## Objective
To develop a Python program that calculates a student's total marks, average marks, grade, and pass or fail status.

## Problem Description
Students need a simple way to analyze their academic performance based on marks obtained in multiple subjects.

This program accepts marks for five subjects, calculates the total and average, assigns a grade, and determines whether the student has passed or failed.

## Concepts Used
- Variables
- User Input
- Data Types
- Arithmetic Operators
- Conditional Statements (if, elif, else)

## Program Description
The program accepts the student's name and marks in five subjects.

It calculates the total marks and average, assigns a grade based on the average, and displays the final result.

## Grading Criteria
- 90 and above – Grade A
- 80 and above – Grade B
- 70 and above – Grade C
- 60 and above – Grade D
- 50 and above – Grade E
- Below 50 – Grade F (Fail)

## Conclusion
This case study demonstrates how Python can be used to analyze student performance using arithmetic operations and conditional statements.
