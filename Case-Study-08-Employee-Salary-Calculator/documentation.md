# Case Study 08: Employee Salary Calculator

## Objective
To develop a Python program that calculates an employee's gross salary, tax, and net salary based on the basic salary.

## Problem Description
An organization needs a simple salary calculation system to determine employee earnings after adding allowances and deducting tax.

This program accepts the employee name and basic salary, calculates HRA, DA, bonus, gross salary, tax, and net salary.

## Concepts Used
- Variables
- User Input
- Data Types
- Arithmetic Operators
- Conditional Statements (if, else)

## Program Description
The program accepts the employee's name and basic salary.

It calculates:
- HRA – 20% of basic salary
- DA – 10% of basic salary
- Bonus – 5% of basic salary
- Gross Salary – Basic salary + HRA + DA + Bonus
- Tax – 10% if gross salary is Rs. 50,000 or above; otherwise 5%
- Net Salary – Gross salary minus tax

## Features
- Salary allowance calculation
- Gross salary calculation
- Tax calculation
- Net salary calculation

## Conclusion
This case study demonstrates how Python can be used to calculate employee salary details using arithmetic operations and conditional statements.
