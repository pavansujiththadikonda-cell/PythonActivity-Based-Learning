# Case Study 02: Warehouse Inventory Reconciliation

## Objective
To develop a Python program that reconciles warehouse inventory by comparing expected stock quantities with actual stock quantities.

## Problem Description
Warehouses need to maintain accurate inventory records. Sometimes the actual stock may differ from the expected stock due to errors, damage, or missing items.

This program compares expected and actual stock quantities and identifies whether the inventory is matched, surplus, or short.

## Concepts Used
- Variables
- User Input
- Data Types
- Arithmetic Operators
- Conditional Statements (if, elif, else)
- Absolute Value Function

## Program Description
The program accepts the product name, expected stock quantity, and actual stock quantity from the user.

It calculates the difference between actual and expected stock and displays the inventory status.

## Possible Results
1. Stock Matched – Expected and actual quantities are equal.
2. Surplus Stock – Actual quantity is greater than expected quantity.
3. Stock Shortage – Actual quantity is less than expected quantity.

## Conclusion
This case study demonstrates how Python can be used for basic warehouse inventory reconciliation through user input, arithmetic operations, and conditional statements.
