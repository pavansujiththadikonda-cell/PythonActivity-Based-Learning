# Case Study 09: Travel Expense Tracker

## Objective
To develop a Python program that records travel expenses, displays recorded expenses, and calculates the total expenditure.

## Problem Description
Travelers need a simple way to record and manage their expenses during a trip.

This program allows users to add expenses under different categories, view the recorded expenses, and calculate the total amount spent.

## Concepts Used
- Variables
- User Input
- Lists
- List Methods (append)
- Built-in Functions (sum, len, range)
- Conditional Statements (if, elif, else)
- While Loop
- For Loop
- Break Statement

## Program Description
The program maintains two lists: one for expense categories and another for expense amounts.

Users can select from a menu of options:
1. Add Expense
2. View Expenses
3. Calculate Total
4. Exit

The program stores expenses, displays them, and calculates the total expenditure.

## Features
- Add expenses under categories
- View recorded expenses
- Calculate total expenses
- Validate expense amounts
- Menu repetition using a while loop

## Conclusion
This case study demonstrates how Python lists, loops, conditional statements, and built-in functions can be used to manage and calculate travel expenses.
