# Case Study 04: Simple Billing & Discount Calculator

## Objective
To develop a Python program that calculates a purchase bill and applies discounts based on the total purchase amount.

## Problem Description
A shop needs a simple billing system to calculate the total cost of purchased items and apply discounts based on purchase value.

This program accepts customer details, item name, quantity, and price per item. It calculates the total amount, applicable discount, and final bill.

## Concepts Used
- Variables
- User Input
- Data Types
- Arithmetic Operators
- Conditional Statements (if, elif, else)

## Program Description
The program accepts the customer's name, item name, quantity, and price per item.

It calculates the total bill and applies a discount according to the purchase amount.

## Discount Criteria
- ₹5000 or above – 20% discount
- ₹3000 or above – 10% discount
- ₹1000 or above – 5% discount
- Below ₹1000 – No discount

## Conclusion
This case study demonstrates how Python can be used to automate a basic billing process using arithmetic operations and conditional statements.
