# Python Activity-Based Learning

## About the Project
This repository contains 10 Python case studies developed as part of an Activity-Based Learning assignment. Each case study focuses on solving a practical problem using Python programming concepts.

## Case Studies

1. Attendance Recovery Computation
2. Warehouse Inventory Reconciliation
3. Student Grade Analyzer
4. Simple Billing & Discount Calculator
5. Electricity Bill Calculator
6. ATM Transaction Simulator
7. Library Book Management System
8. Employee Salary Calculator
9. Travel Expense Tracker
10. Online Quiz System

## Concepts Covered
- Variables and Data Types
- Input and Output
- Conditional Statements
- Loops
- Lists
- Functions and Calculations
- Basic Problem Solving

## Project Structure
Each case study contains:
- `main.py` – Python program
- `documentation.md` – Case study documentation
