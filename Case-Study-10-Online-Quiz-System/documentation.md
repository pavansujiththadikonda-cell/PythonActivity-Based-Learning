# Case Study 10: Online Quiz System

## Objective
To develop a Python program that conducts a simple quiz, evaluates answers, calculates scores, and displays the final result.

## Problem Description
An online quiz system allows users to answer questions and receive results based on their performance.

This program displays five multiple-choice questions, accepts user answers, checks whether the answers are correct, and calculates the final score.

## Concepts Used
- Variables
- User Input
- Lists
- Nested Lists
- List Indexing
- Conditional Statements (if, elif, else)
- For Loop
- Built-in Functions (len)

## Program Description
The program stores questions, options, and correct answers in lists.

It displays each question along with four options. The user enters an answer, and the program checks whether it is correct.

At the end, the program calculates the correct answers, wrong answers, final score, and performance grade.

## Features
- Multiple-choice questions
- Four options for each question
- Automatic answer checking
- Score calculation
- Performance feedback

## Conclusion
This case study demonstrates how Python lists, loops, conditional statements, and user input can be used to create a simple quiz system.
